# A&J เช็คอิน

แอปลงเวลาพนักงานร้าน A&J ที่สนามบิน เปิดใช้งานผ่าน LINE (LIFF)

- **พนักงาน**: ถ่ายรูปเข้างานและปิดร้าน ดูกะของตัวเอง ดูประวัติ เปลี่ยนรูปประจำตัวได้เอง
- **ผู้จัดการ**: จัดตารางเวรวันรุ่งขึ้นทุกเย็น ส่งรูปและข้อความเข้ากลุ่ม LINE แล้วส่งให้หัวหน้าตรวจ
- **หัวหน้า**: ดูการเข้างานวันนี้ อนุมัติตารางเวร (กะเข้าระบบเมื่ออนุมัติแล้วเท่านั้น) บันทึกความผิด สรุปพิจารณาความดีความชอบ จัดการพนักงาน
- **แอดมิน (ดูแลระบบ แยกจากหัวหน้า)**: `monitor.html` ดูสถานะระบบ และเปิดแอปในฐานะคนอื่นเพื่อทดสอบ

## รูปถ่าย

- รูปเข้างาน/ออกงาน รูปหน้าตรงตอนลงทะเบียน และรูปหลักฐานของหัวหน้า ถ่ายจากกล้องในแอปเท่านั้น เลือกรูปจากเครื่องไม่ได้ (ทั้ง iPhone และ Android)
- เลือกรูปจากอัลบั้มได้ที่เดียว คือเปลี่ยนรูปประจำตัว
- รูปมีตราวันที่และเวลาไทยจากนาฬิกาของเซิร์ฟเวอร์ ไม่ใช้เวลาในมือถือ เวลาที่บันทึกลงงานก็เป็นเวลาของเซิร์ฟเวอร์

## ส่วนประกอบ

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแอปและหน้าตา |
| `app.js` | การทำงานของแอป |
| `config.js` | LIFF ID และที่อยู่ API (ไม่มีรหัสลับ) |
| `monitor.html` | หน้าดูสถานะระบบ สำหรับแอดมินระบบเท่านั้น |
| `supabase/functions/api/index.ts` | API บน Supabase ตรวจตัวตนกับ LINE แล้วเรียกฐานข้อมูล |

ข้อมูลทั้งหมด (พนักงาน กะ เวลาเข้าออก รูป บันทึกความผิด) เก็บใน Supabase และเข้าถึงได้ผ่าน API เท่านั้น
